# 🏥 피부과 의원 자금·손익 관제 대시보드 (검증·보완 완료 버전)

## 1. 검증 보고서 기반 반영 완료 내역
1. **문자(SMS) 파서 6대 버그 수정**:
   - 카드번호 끝 4자리(`1234 승인 50,000원`)를 금액으로 오인식하던 문제 해결 (`원` 접미사 필수 매칭 및 `잔액/누적` 선분리)
   - `[우리은행] 입금 ... 하나카드`를 하나은행으로 오분류하던 문제 해결 (카드사명 선제거 후 발신은행 판별)
   - `승인취소 / 환불` 문자 수신 시 지출 차감(`-`) 처리
   - 문자 내 `잔액 OO,OOO,OOO원` 포함 시 통장 잔액 자동 동기화
   - 내부이체 문자 수신 시 단일 통장만 반영하여 이중 이동 방지 (설정창에서 병원/원장님 성함 키워드 지정 가능)
   - 하나은행 고객 입금 시 환자 실명 자동 마스킹(`최수진` ➔ `최*진`) 및 XSS 스크립트 삽입 방어(`escapeHtml`) 적용
2. **손익(P&L) 및 경영 시뮬레이터 로직 수정**:
   - 누락되었던 **20일 재료비 현금이체(800만 원)** 및 **식대·복리후생(290만 원)**을 손익 산식에 완전 반영 (`실질 순이익 +16,166,000원`)
   - 손익분기점(BEP) 계산식을 공헌이익률 공식(`고정비 ÷ (1 - 변동비율 - 세율)`)으로 정상화
   - 시뮬레이터 적용 시 **원본 병원 데이터를 별도 보존(`realBackupState`)**하고 원클릭 복귀 버튼을 제공하여 실데이터 덮어쓰기 방지
   - 고정되어 있던 `받을 정산금`, `20일 현금재료비`, `세금 적립률(%)`, `내부이체 키워드`를 모두 `⚙️ 초기값 설정`에서 수정 가능하도록 개방
3. **구글 시트 웹훅 양방향 연동 및 비밀 토큰(Secret Token) 보안 적용**:
   - [cloud-deploy/google_sheets_webhook.gs](file:///C:/Users/UPIC/.gemini/antigravity/scratch/clinic-cashflow-dashboard/cloud-deploy/google_sheets_webhook.gs)에 `SECRET_TOKEN` 검증을 추가하여 외부 무단 조회·입력을 차단하고, 대시보드에서 시트 데이터를 읽어오는 양방향 동기화(`syncFromCloudWebhook`)를 구현했습니다.

## 2. 갤럭시 폴드5에서 바로 실행해 보는 방법 (PC에 파이썬/Node 설치 불필요!)

### STEP 1. 대시보드 화면을 폴드5 전용 주소로 올리기 (10초 소요)
1. PC 브라우저에서 **[Netlify Drop (https://app.netlify.com/drop)](https://app.netlify.com/drop)** 에 접속합니다.
2. 탐색기에서 `C:\Users\UPIC\.gemini\antigravity\scratch\clinic-cashflow-dashboard\public` 폴더를 마우스로 끌어다 놓습니다.
3. 생성된 `https://...netlify.app` 주소를 **갤럭시 폴드5**에서 열고 브라우저 메뉴의 **[홈 화면에 추가]**를 누르면 앱처럼 바로 실행됩니다.

### STEP 2. 폴드5 문자 자동전달(구글 시트 웹훅) 연결하기 (3분 소요)
1. 구글 스프레드시트를 새로 만들고 상단 메뉴 **[확장 프로그램] ➔ [Apps Script]**를 엽니다.
2. `cloud-deploy/google_sheets_webhook.gs` 파일 내용을 붙여넣고, 상단 `SECRET_TOKEN` 값을 원장님만의 비밀번호로 바꿉니다.
3. 우측 상단 **[배포] ➔ [새 배포] ➔ 유형: [웹 앱]** (실행 주체: `나`, 액세스 권한: `모든 사용자`)으로 배포 후 **웹 앱 URL**을 복사합니다.
4. 갤럭시 폴드5의 문자 전달 앱(SMS Forwarder)에 아래와 같이 등록합니다:
   - **발신번호 화이트리스트 (OTP 유출 방지)**: 우리은행(`15885000`), 하나은행(`15991111`), 경남은행(`16008585`), 사용 카드사 번호만 지정
   - **전달 URL**: `복사한_웹앱_URL?token=원장님비밀토큰`
   - **JSON 본문**: `{"text": "%sms%"}`
5. 대시보드 상단 **[☁️ 폴드5 클라우드 연결]** 버튼을 눌러 동일한 웹 앱 URL과 비밀 토큰을 입력하고 **[🔄 저장 & 지금 시트에서 불러오기]**를 누르면 폰과 PC가 실시간으로 동기화됩니다.
