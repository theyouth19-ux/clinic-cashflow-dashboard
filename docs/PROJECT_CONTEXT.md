## 1. 원장님 병원 자금·결제 환경 (확정 사항)

### ① 운영 방식: 『팝빌(Popbill) 무인 자동 수집 + PC & 갤럭시 폴드5 동시 열람』
- **핵심 원칙**:
  - 원장님 휴대폰에는 은행 입출금 알림이 오지 않으며, 휴대폰(카카오톡 등)에 외부 앱을 설치하지 않는 **100% 휴대폰 무설치 안전 방식** 채택.
  - 갤럭시아머니트리 관리자(`cpadmin.billgate.net`)는 보안문자+2차인증으로 인해, 은행 사이트(우리·경남)는 PC 보안모듈(TouchEn/nProtect)로 인해 직접 스크래핑 대신 **팝빌(Popbill) 계좌조회 API (계좌당 월 5,000원 × 2계좌 = 월 10,000원 · 첫 달 무상 테스트)**로 **우리은행 + 경남은행** 2개 통장만 무인 자동 연동함.

### ② 2개 자동연동 통장 역할 분담 (하나은행은 연동 제외)
1. **🟦 우리은행 (`1005-104-863854` 지정 계좌 전용 · 타 우리은행 계좌 자동 제외)**
   - **입금**:
     - `갤럭시아머니트리` PG 정산금 (단말기별로 우리/경남 입금 은행이 다름)
     - 무선단말기 카드사별 정산금 (`신한카드`, `삼성카드`, `하나카드` 등)
     - **고객 현금입금 (원장님 직접 입금)**: 하나은행으로 들어온 고객 현금수입을 원장님이 직접 우리은행에 고객 현금입금으로 입금하므로, 우리은행 입금 내역에서 현금수입으로 자동 반영
   - **출금**: 병원의 **모든 지출(출금)**은 우리은행(`1005-104-863854`) 한 곳에서만 나감
2. **🟧 경남은행**
   - **입금**: `갤럭시아머니트리` PG 정산금(일부 단말기) + 무선단말기 카드 + **강남언니(`힐링페이퍼`)**, **언니가이드** 정산금 입금
- **🚫 하나은행**: 고객 현금 입금 경로이나, 원장님이 직접 우리은행으로 입금하시므로 자동연동(팝빌) 및 대시보드 통장 잔액 합산에서 제외함.
- **🔄 내부 이체 분리**: **우리은행 ↔ 경남은행** 간 자금을 옮길 때 발생하는 입출금은 **'통장 간 내부이체'**로 분류하여 매출/지출 합산에서 중복 제외함.

### ③ 갤럭시아머니트리 정산 주기 규칙
- **신용카드**: 결제일 기준 **영업일 +1일(D+1)** 입금
- **위챗페이 · 알리페이 · 기타(간편결제 등)**: 결제일 기준 **영업일 +3일(D+3)** 입금
- 우리은행·경남은행에 역할 구분 없이 단말기(대출 조건)에 따라 나누어 입금됨.
