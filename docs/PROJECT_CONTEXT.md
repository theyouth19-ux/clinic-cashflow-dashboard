## 1. 원장님 병원 자금·결제 환경 (확정 사항)

### ① 운영 방식: 『월 0원 엑셀/CSV 업로드(메모 포함 · `.xlsx/.xls/.csv`) + 월별 결산 + 세금/평가 자동진단』
- **핵심 원칙**:
  - 원장님 휴대폰에는 은행 입출금 알림이 오지 않으며, 휴대폰에 외부 앱을 설치하지 않는 **100% 휴대폰 무설치 안전 방식** 채택.
  - 팝빌 API(계좌당 월 10만 원) 대신 **로컬 SheetJS(`public/xlsx.full.min.js`)**를 내장해 우리은행 로그인 엑셀(`.xlsx`/`.xls`/`.csv`/HTML `.xls`)과 경남은행 빠른조회·홈페이지 조회 파일(`.xlsx`/`.xls`/`.csv`)을 은행별 전용 버튼으로 업로드하는 **월 0원 방식**을 사용함.
  - 업로드 시 `계좌 + 거래일시 + 입출금액 + 거래후잔액 + 적요` 기반 중복 검증(`processedIds`)과 **기존 거래 소급 메모 보완(`enrichExistingMemoTx`)**을 수행하며, 업로드된 파일명 표시 및 `우리은행 로그인` / `경남은행 빠른조회` 바로가기 버튼을 제공함.
  - 탭 구조는 **`🏆 손익` → `📅 기간` → `📊 항목`(비중 높은 순 정렬) → `💳 카드` → `🩺 평가`** 5개 탭으로 구성하며(`시점` 탭 제거), 기본 글자 크기 `116%`(+2단계) 및 `가-`/`가+` 조절 기능을 지원함.

### ② 2개 자동연동 통장 역할 분담 (하나은행은 연동 제외)
1. **🟦 우리은행 (`1005-104-863854` 지정 계좌 전용 · 타 우리은행 계좌 자동 제외)**
   - **입금**:
     - `갤럭시아머니트리` PG 정산금 (단말기별로 우리/경남 입금 은행이 다름)
     - 무선단말기 카드사별 정산금 (`신한카드`, `삼성카드`, `하나카드` 등)
     - **고객 현금입금 (원장님 직접 입금)**: 하나은행으로 들어온 고객 현금수입을 원장님이 직접 우리은행에 고객 현금입금으로 입금하므로, 우리은행 입금 내역에서 현금수입으로 자동 반영
   - **출금**: 병원의 **모든 지출(출금)**은 우리은행(`1005-104-863854`) 한 곳에서만 나감
2. **🟧 경남은행**
   - **입금**: `갤럭시아머니트리` PG 정산금(일부 단말기) + 무선단말기 카드 + **강남언니(`힐링페이퍼`)**, **언니가이드** 정산금 입금
- **🚫 하나은행**: 고객 현금 입금 경로이나, 원장님이 직접 우리은행으로 입금하시므로 자동연동(팝빌) 및 대시보드 통장 잔액 합산에서 제외함.
- **🔄 내부 이체 분리**: **우리은행 ↔ 경남은행** 간 자금을 옮길 때 발생하는 입출금은 **'통장 간 내부이체'**로 분류하여 매출/지출 합산에서 중복 제외함.

### ③ 갤럭시아머니트리 정산 주기 규칙
- **신용카드**: 결제일 기준 **영업일 +1일(D+1)** 입금
- **위챗페이 · 알리페이 · 기타(간편결제 등)**: 결제일 기준 **영업일 +3일(D+3)** 입금
- 우리은행·경남은행에 역할 구분 없이 단말기(대출 조건)에 따라 나누어 입금됨.

### ④ 결산 기준 (`매월 1일 ~ 말일`), 사업자 신용카드 및 상세 분류 규칙

- **세금 별도 관리 & 국내 세법 계산 (`#pnl-ytd-tax-card`)**:
  - 월별 영업순이익에서는 부가세·종소세 적립과 일시납(`부가세 확정·선납`, `종소세·선납`)을 제외하고, 해당 달 일시납 금액은 손익 명세 하단에 별도 항목으로 표시함.
  - **부가세(`5.0%`)**: 1~6월 누적 후, **7월 상반기 확정납부 완료 시 7월부터 0원으로 리셋**하며 하반기 선납(`26년후반기절반선납` 등)은 자동 차감함.
  - **종합소득세**: **매년 1월 ~ 선택월** 누적 영업순이익(부가세 제외)에 **대한민국 소득세법 누진세율(6~45% + 지방소득세 10%)**을 적용하고 올해분 선납(`종합소득세 선납`)을 차감해 계산 과정·실효세율·남은 예상세액을 표시함.
- **미입금 보유현금 & `🩺 평가` 탭**:
  - 통장에 미입금된 보유현금(`unbankedCash`, 예: 4,900만 원)을 입력하면 1/1~현재 총매출·영업순이익·총 보유자금·세금 계산에 반영되며, 추후 통장 입금 시 메모에 `보유현금입금`을 적으면 매출 중복 없이 자동 차감됨.
  - `🩺 평가` 탭에서 **`💎 세금뺀 순수 자금`**(보유자금 - 남은 부가세·종소세) 및 긍정·부정·개선점 3가지 실시간 진단을 제공함.
