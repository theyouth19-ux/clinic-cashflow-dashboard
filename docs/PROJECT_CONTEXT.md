> **💡 다른 컴퓨터에서 작업을 이어갈 때**:

>
> **`"docs/PROJECT_CONTEXT.md 와 docs/verification_report.md 를 읽고 피부과 대시보드 작업을 이어서 진행하자."`**

## 1. 원장님 병원 자금·결제 환경 (확정 사항)

### ① 스마트폰 및 사용 환경
- **기종**: **갤럭시 폴드5 (안드로이드)** + 원장실/자택 PC 겸용
- **화면 요구사항**:
  - **폴드5 접은 화면 (커버 스크린)**: 글자가 아이콘이나 카드를 넘기지 않도록 탭 이름을 2글자(`손익 / 시점 / 카드 / 기간 / 항목`)로 줄이고 항목명을 간결하게 배치한 컴팩트 뷰
  - **폴드5 펼친 화면 / PC**: 넓은 다중 컬럼 대시보드 뷰

### ② 3개 은행 통장 역할 분담
1. **🟦 우리은행 (주거래 정산 + 병원 전체 출금 전담)**
   - **입금**: 유선단말기 PG 정산금(`갤럭시아머니트리` 이름으로 신용카드+네이버페이+카카오페이 합산 입금), 무선단말기 카드사별 정산금(`신한카드`, `삼성카드` 등 직접 입금)
   - **출금**: 병원의 **모든 지출(출금)**은 우리은행 한 곳에서만 나감
2. **🟩 하나은행 (고객 현금입금 / 계좌이체 수납 전용)**
   - **입금**: 환자가 직접 계좌이체로 입금하는 현금수입 (입금자명: 환자 실명 ➔ 개인정보 보호를 위해 `박*현` 형태로 자동 마스킹 처리)
3. **🟧 경남은행 (미용 플랫폼 정산 전용)**
   - **입금**: **강남언니(`힐링페이퍼`)**, **언니가이드** 정산금 입금 전용
- **🔄 내부 이체 분리**: 하나은행·경남은행에서 지출용인 우리은행으로 자금을 옮길 때 발생하는 입출금은 **'통장 간 내부이체'**로 분류하여 매출/지출 합산에서 중복 제외함.

### ③ 사업자 신용카드 및 월간 지출 캘린더 (`매월 21일` 공식 기준일)
- **사업자 신용카드 (2그룹 모두 `전월 1일 ~ 전월 말일` 사용분 산정)**:
  1. **1차 일반 사업자카드**: **매월 14일** 우리은행에서 출금 (`전월 1일 ~ 말일` 사용분)
  2. **2차 BNK경남은행 카드**: **매월 20일** 출금 (`전월 1일 ~ 말일` 사용분)
- **월간 지출 릴레이 일정**:
  - **매월 5일**: 직원 급여 + 의료장비 리스료 출금
  - **매월 10일**: 원천세 + 4대보험 + 임대·관리비 출금
  - **매월 14일**: 1차 일반 사업자카드 대금 출금 (전월 1~말일 사용분)
  - **매월 20일**: 2차 경남은행 카드 대금 출금 (전월 1~말일 사용분) + **거래처 재료비 현금이체** *(※ 20일, 27일, 28일경 카드로 결제하는 재료비는 해당 월 카드 사용분에 포함되어 익월 14일/20일에 출금됨)*
- **🚩 공식 손익 확정 및 현금 비교 기준일 = 『매월 21일』**:
  - 매월 5일~20일 사이에 한 달 주기 지출이 모두 빠져나가므로, **매월 21일**을 공식 기준일로 삼아 ① 전월 귀속 실질 순이익(흑자/적자) 확정, ② `전월 21일 vs 당월 21일` 3개 통장 총잔액 순증감 비교를 수행함.

## 2. 지금까지의 작업 단계 및 대화 요약

1. **1단계 (기획 및 프로토타입 설계)**:
   - 시점별 현금흐름(통장 잔액 + 받을 정산금 - 나갈 카드·재료비 = 실질 가용현금), 기간별 현금흐름, 항목별 흐름(수입 6대 채널 & 지출 5대 항목), 그리고 **아직 통장에서 출금되기 전인 '신용카드 결제시점(승인일) 기준 대시보드 & 14·20일 출금일 관리'** 화면 구축.
   - 매월 21일 공식 기준일 기반 **월간 손익(이익/손실) 판정 대시보드**를 1번 메인 탭으로 배치하고, 폴드5 접은 화면 레이아웃 최적화.
2. **2단계 (시뮬레이터 및 클라우드 배포 구성)**:
   - `🧪 비용절감·매출증가 손익 시뮬레이터(What-If)` 및 `⚙️ 우리 병원 초기값 설정 창` 구현.
   - 구글 시트 기반 24시간 무료 웹훅(`cloud-deploy/google_sheets_webhook.gs`) 및 GitHub Pages 모바일 웹앱 배포(`https://theyouth19-ux.github.io/clinic-cashflow-dashboard/`).
3. **3단계 (Opus 모델 비판적 검증 및 코드 보완 완료)**:
   - 검증 보고서(`docs/verification_report.md`)에서 도출된 이슈 중 즉시 수정 가능한 항목 반영 완료:
     - **문자 파서 6대 버그 수정**: 카드번호 4자리(`1234`) 금액 오인식 방지, `'하나카드'`를 하나은행으로 오분류하던 버그 해결, `승인취소` 차감 처리, 문자 내 `잔액 OO원` 자동 동기화, 내부이체 단일 계좌 처리, 환자 실명 마스킹(`최*진`) 및 XSS 방어.
     - **손익 산식 수정**: 누락되었던 `20일 현금이체 재료비(800만 원)` 손익 반영, 공헌이익률 기반 `손익분기점(BEP)` 공식 수정, 시뮬레이터 적용 시 원본 실데이터 백업·복귀 기능 추가.
     - **양방향 연동 및 보안**: 구글 시트 웹훅에 `SECRET_TOKEN` 인증 추가 및 대시보드에서 시트 데이터를 읽어오는 양방향 동기화 구현.
