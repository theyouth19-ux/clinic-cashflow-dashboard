### 1. 왜 '모바일(문자·알림 연동)' 방식이 완전 자동화에 유리한가?

은행 API나 공인인증서 방식은 인증서가 만료되거나 보안 정책이 바뀌면 다시 연동해야 하는 번거로움이 있습니다. 반면 **통장 입출금 문자(SMS)나 은행 앱 푸시 알림**은 돈이 들어오고 나가는 **그 즉시(0.1초 만)**에 원장님 휴대폰으로 날아옵니다.

휴대폰에 날아오는 문자를 자동으로 읽어서 대시보드 서버로 쏘아주게 만들면, **손 하나 까딱 안 해도 실시간으로 아래 분류가 자동 완성**됩니다.

```
📱 [휴대폰으로 입출금 문자 수신] ──(즉시 자동 전송)──▶ 📊 [대시보드 실시간 자동 분류]

1) "입금 8,540,000원 갤럭시아머니트리 잔액 45,200,000원"
   ➡️ [PG 정산금 유입]으로 분류 + 해당 통장 실시간 잔액 4,520만 원으로 자동 갱신

2) "입금 1,320,000원 신한카드(또는 비씨/현대 등)"
   ➡️ [무선단말기 카드 정산금 유입]으로 자동 분류

3) "입금 330,000원 김미영(환자이름)" (수납 통장)
   ➡️ [계좌이체 현금수입]으로 자동 분류

4) "출금 5,000,000원 내 병원 다른 통장"
   ➡️ [통장 간 내부 이체]로 자동 인식 (수입·지출 중복에서 자동 제외)
```

* **안드로이드(갤럭시 등) 사용 시**: 전용 백그라운드 앱(또는 알림 포워더)이 문자와 카톡 알림톡을 100% 무인으로 읽어서 대시보드에 바로 넣어줍니다.

### 2. 핵심 과제 해결: `'갤럭시아머니트리'`로 합쳐서 들어오는 돈, 어떻게 쪼갤까?

2. **PG(갤럭시아머니트리) & 무선단말기 세부 내역 (새벽/실시간 무인 수집 봇)**
